# 🎮 블록 블라스트! (Block Blast Web)

오리지널 **블록 블라스트(Block Blast)** 퍼즐 게임의 핵심 규칙과 재미를 완벽하게 구현한 웹 기반 게임입니다.
별도의 설치나 복잡한 설정 없이 브라우저에서 바로 실행하여 PC와 모바일 모두에서 즐길 수 있습니다.

---

## 🌟 주요 기능 및 특징

1. **8x8 클래식 그리드 & 정밀한 블록 판정**
   - 1x1 단일 블록부터 5칸 막대, L자, T자, 2x2, 3x3 등 다채로운 블록 모양 지원.
   - 드래그 중 배치 가능한 위치에 실시간 고스트(그림자) 미리보기 표시.

2. **직관적인 조작법 (두 가지 모드 동시 지원)**
   - **드래그 & 드롭 (Drag & Drop)**: 하단 블록을 마우스나 손가락으로 끌어서 원하는 위치에 놓기. (모바일 터치 시 손가락에 시야가 가리지 않도록 상단 오프셋 적용)
   - **탭 & 배치 (Tap to Place)**: 하단 블록을 한 번 클릭/터치하여 선택한 후 보드의 원하는 칸을 클릭하여 배치.

3. **연속 콤보(Combo) & 폭발 이펙트**
   - 가로 또는 세로 줄이 가득 차면 즉시 시원하게 블라스트(폭발)!
   - 여러 줄을 동시에 터뜨리면 추가 보너스 점수 획득.
   - 연속으로 줄을 제거할 때마다 **COMBO x2, COMBO x3...** 콤보 스트릭과 화려한 축하 연출.
   - Canvas 기반 파티클 폭발 및 점수 팝업 애니메이션.

4. **공정한 스마트 블록 생성 알고리즘**
   - 새 블록 3개가 생성될 때 현재 보드에 최소 1개 이상 배치 가능한 블록이 주어지도록 보장.
   - 현재 보드에 둘 수 없는 블록은 하단에서 살짝 어둡게 표시되어 상황 파악 용이.

5. **자체 Web Audio API 사운드 신시사이저**
   - 외부 오디오 파일 다운로드 없이 브라우저 자체 오디오 엔진으로 사운드 합성 출력.
   - 블록 집기, 놓기, 줄 제거(콤보가 올라갈수록 음계 상승!), 게임오버 효과음 탑재.
   - 우측 상단 🔊 버튼으로 손쉽게 음소거/음소거 해제 가능.

6. **최고 점수 저장 (Best Score)**
   - 플레이어의 최고 기록이 브라우저 로컬 저장소(`localStorage`)에 자동 저장.

## 🚀 실행 방법

### 방법 1: 브라우저로 직접 열기 (가장 간단)
1. 탐색기에서 다음 경로로 이동합니다:
   `C:\Users\A\.gemini\antigravity\scratch\block-blast`
2. `index.html` 파일을 더블 클릭하면 기본 웹 브라우저(Chrome, Edge 등)에서 즉시 게임이 실행됩니다!

### 방법 2: VS Code / Live Server 사용
VS Code 또는 에디터의 Live Server 확장이 있다면 `index.html` 우클릭 후 **"Open with Live Server"** 를 누르면 로컬 웹 서버로 즐길 수 있습니다.
